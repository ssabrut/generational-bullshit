# generational-bullshit — Floor Plan Understanding Pipeline

Computer vision pipeline that ingests raw floor plan PNG images and outputs a
structured JSON graph of walls, doors, and windows.

---

## Full Pipeline (single image)

```
raw PNG
  │
  ▼  Step 1 — Text removal
  │  preprocessing/preprocessing.py :: FloorPlanPreprocessor._remove_text()
  │  • OCR at 4 angles (0°, 90°, 180°, 270°) via EasyOCR
  │  • Builds a combined text mask across all angles
  │  • Erases text pixels → white
  │  ├─► raw_no_text   (BGR, uncropped)   ← save to data/PNG/no_text/
  │  └─► rotation_angle (int°)            ← correct upright orientation
  │
  ▼  Step 2 — Preprocessing
  │  preprocessing/preprocessing.py :: FloorPlanPreprocessor._enhance()
  │  • Grayscale → Gaussian blur (k=5) → Otsu binarisation
  │
  ▼  Step 3 — Crop & pad
  │  preprocessing/preprocessing.py :: FloorPlanPreprocessor._crop_and_pad()
  │  • Bounding box of non-zero pixels + 100px padding
  │  • Apply SAME bbox to raw_no_text  → cropped color image for detection
  │  ├─► preprocessed  (binary, cropped) ← save to data/PNG/crop_and_pad/
  │  └─► crop_bbox     (x1,y1,x2,y2)    ← coordinate bridge between outputs
  │
  ▼  Step 4 — Skeleton + corner graph    (on preprocessed binary image)
  │  notebooks/skeleton_corner_detection.ipynb
  │  • Skeletonize → polygon corner detection → NMS → BFS edge discovery
  │  • Builds a NetworkX Graph  G  with corner nodes and wall edges
  │
  ▼  Step 5 — Object detection           (on cropped raw_no_text color image)
  │  notebooks/skeleton_door_graph.ipynb  :: detect_openings()
  │  • YOLO inference (Models/best_v2.pt or best_v3.pt)
  │  • Classes: door, 2door, window  (8-class SFPI model adds armchair, bed, …)
  │
  ▼  Step 6 — Graph fusion + JSON export
     notebooks/skeleton_door_graph.ipynb  (final cell)
     • Each detected opening → new node connected to nearest corner
     • "touching" = opening bbox within SNAP_PX (20px) of a corner endpoint
     • Output JSON:
       {
         "walls":   [{"from":[x,y], "to":[x,y], "length":px}, …],
         "doors":   [{"center":[x,y], "bbox":[…], "connected_to":[x,y],
                      "touching_corners":[[x,y],…], "conf":0.9}, …],
         "windows": […same schema as doors…]
       }
```

## Data Layout

```
data/
  PNG/
    raw/           ← original scanned PNGs (source)
    no_text/       ← step 1 output: BGR, text erased
    crop_and_pad/  ← step 3 output: binary, cropped (used by skeleton pipeline)
  SFPI/
    Images/{train,val,test}/   ← TIFF floor plans
    Annotations/{split}_annotation.json  ← COCO format
    labels/{train,val,test}/   ← YOLO .txt labels (generated by object.ipynb cell 3)
    data.yaml                  ← YOLO config
```

## Class Merges (SFPI dataset)

The SFPI dataset originally had 16 numbered variant classes. These are merged
to 8 for training:

| Original | Merged |
|----------|--------|
| door1, door2 | door |
| sink1–sink4 | sink |
| sofa1, sofa2 | sofa |
| table1–table3 | table |
| window1, window2 | window |
| armchair, bed, tub | (unchanged) |

## Using `FloorPlanPreprocessor`

```python
import cv2
from preprocessing.preprocessing import FloorPlanPreprocessor

pp     = FloorPlanPreprocessor(angle_step=90)   # 4 angles; use 30 for thoroughness
result = pp.process(cv2.imread("image.png"))

result.rotation_angle   # int — clockwise degrees for upright orientation
result.crop_bbox        # (x1, y1, x2, y2) in raw_no_text space
result.raw_no_text      # BGR numpy array, text removed, NOT cropped
result.preprocessed     # binary numpy array, cropped — feed to skeletoniser
```

To get the cropped color image for YOLO (same spatial window as `preprocessed`):
```python
x1, y1, x2, y2 = result.crop_bbox
cropped_color = result.raw_no_text[y1:y2, x1:x2]
```

## Notes

- `crop_bbox` is the coordinate bridge: all skeleton node coordinates are in
  the `preprocessed` (cropped) space. Use `crop_bbox` to map them back to
  `raw_no_text` space if needed.
- YOLO must receive the **color** image (not the binary preprocessed one) for
  reliable detection — the door/window textures and colours matter.
- `data/SFPI/images` is a symlink → `data/SFPI/Images` (lowercase) so YOLO's
  `/images/` → `/labels/` path substitution works correctly.
- Re-run the COCO→YOLO conversion cell in `object.ipynb` whenever the class
  merge mapping changes — it regenerates all `labels/` txt files.
